# 4. Kitchen screen and token screen

## Kitchen screen – Kitchen ▾ → Kitchen

What it is for: the kitchen sees every order the moment it is placed, without paper.

- Each ticket shows the token, table or customer name, items with sizes/extras and notes (e.g. Jain).
- Ticket labels: **New**, **Waiting** (minutes since order) and **Late**.
- Tap to move a ticket: **Preparing** → **Ready**. A new round on an open table shows as a new ticket for the same token.
- With kitchen stations, each station can see only its own items and prints its own KOT.
- A kitchen tablet can stay signed in for days (kitchen device login).

## Token screen – Kitchen ▾ → Token screen

What it is for: a TV or tablet facing guests showing which tokens are ready to collect.

- Tokens appear when the kitchen marks them Ready.
- They disappear when staff tap Food delivered / Handed over, or automatically after 15 minutes.
- Put it full-screen on a spare screen near the counter.
