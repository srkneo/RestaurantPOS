# 7. Reservations

## Reservations – Orders ▾ → Reservations

What it is for: table bookings by phone or walk-in, so a table is kept for the guest.

### Book a table

1. Tap **New reservation**.
2. Guest name, phone (optional), people, date, time, table (or **Any table**) and a note (e.g. birthday, window seat).
3. **Save**. The same table cannot be booked twice within 90 minutes; the message tells you who already has it.

### On the day

- Pick the **Day** to see its bookings in time order with status: Booked, Seated, Cancelled, No-show.
- When the guests arrive tap **Seat**, then take their order on the POS as usual.
- **Cancel booking** or **No-show** if they don't come. **Undo** fixes a mistake. **Edit** changes a booked one.
- In the POS table grid, a table booked in the next two hours shows **Reserved 20:30 · Patel**.
