# 12. Common questions and fixes

**The table still shows busy after payment.** That is on purpose: guests may still be sitting. Tap **Customer left** in the table grid.

**Guests want more after the bill was printed.** Add the items to the same table on the POS; they join the same token and bill. Print the bill again. If any money was already received, start a new order.

**Guest is ₹3 short and there is no change.** Record what they paid, then **Waive small change**. Limit set in Admin ▾ → Billing.

**"Take payment or void the bill" / "already paid" message.** The bill has a payment, so it cannot change. Make a new order for extra items.

**Discount refused.** It is above the cashier limit: a manager types their PIN.

**A dish should not be sold today.** Menu → switch **Available** off.

**Stock shows below zero.** Recipes took more than was recorded as bought. Record the purchase or do a **Counted** entry.

**Reports "Today" shows last night after midnight.** Correct: the business day starts at 4 AM.

**The internet went off.** On cloud, the POS keeps orders and sends them when the internet is back (do not close the browser). On a shop PC, billing works fully offline.

**Bill prints in the wrong language or size.** Admin ▾ → Billing → Bill and KOT language / Paper width.

**Forgot password.** Owner: Forgot password? on sign-in. Staff: the owner resets it on Admin ▾ → Staff.

**Subscription stopped banner.** Pay by UPI/bank transfer and send the reference to support; service resumes as soon as the payment is recorded.

**Need help.** Tap **?** → Help, or call/WhatsApp support (hours shown there).
