# 10. Shop PC edition: licence, updates and backups

For restaurants that keep bills on their own PC (no internet needed for billing).

## Licence – Admin ▾ → Licence

- Shows the licence status, customer, plan and expiry, and the **device code** of this PC.
- A new install has a **30-day trial**. To activate, send the device code to support; enter the licence key you get back.
- The licence renews itself whenever the PC is online and works **7 days without internet**. Warnings start 15 days before expiry; after expiry no new orders, but old bills stay viewable and exportable.

## Updates

- The PC updates itself at **3:30 AM** if a newer version is out (shop PCs wait 2 days after a release so cloud users try it first).
- **Update now** installs at once; **Early** takes new versions without the wait; **Pause** stops updates; **Pin** stays on one version.
- If an update fails, it rolls back to the previous version by itself.

## Backups

- A backup is made every night. Copy backups to a USB drive or network folder from the Licence page.
- A warning shows if the last copy is too old.

## Power cut

The app starts by itself when the PC is switched on again. Orders placed on the tablets while the PC was off wait and are sent when it is back.
