# User Guide – RestaurantPOS (how to use, non-technical)

This guide explains every part of RestaurantPOS in plain words: what each screen is for and how to use it step by step. It is written for restaurant owners, managers, cashiers, waiters and kitchen staff, and for Mahesh as the platform owner.

> Version covered: 1.9.7 (20 Nov 2026) plus the grouped menu and stock report that go out with the next release.
> 

## Who sees what

| Role | What they use | Main menu they see |
| --- | --- | --- |
| Owner (Admin) | Everything for their restaurant | POS, Orders ▾, Kitchen ▾, Menu & stock ▾, Reports ▾, Admin ▾ |
| Manager | Daily running, menu, stock, reports, approvals with PIN | POS, Orders ▾, Kitchen ▾, Menu & stock ▾, Reports ▾ |
| Cashier | Taking orders, bills and payments, day close, expenses, stock entries | POS, Orders ▾, Stock |
| Waiter (captain) | Taking orders at tables, reservations | POS, Reservations |
| Kitchen | Kitchen screen and token screen, stock entries | Kitchen ▾, Stock |
| Platform owner (Mahesh) | All restaurants, subscriptions, support details, shop licences | Platform, Licences, Support |
